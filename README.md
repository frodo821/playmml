# PlayMML

MML (Music Macro Language) パーサー・プレイヤー。MMLテキストを解析し、オーディオとして再生、またはWAVファイルとして出力する。

## MML仕様

### 概要

MMLテキストは**空白区切り**のトークン列として解析される。各トークンはノート名、ディレクティブ、またはオクターブ操作子のいずれかである。

### ノート

以下の12音がトークンとして使用できる：

| トークン | 音名 |
|---------|------|
| `C`     | ド   |
| `C#`    | ド#  |
| `D`     | レ   |
| `D#`    | レ#  |
| `E`     | ミ   |
| `F`     | ファ |
| `F#`    | ファ# |
| `G`     | ソ   |
| `G#`    | ソ#  |
| `A`     | ラ   |
| `A#`    | ラ#  |
| `B`     | シ   |

- フラット記法（`Db`, `Eb` 等）は**サポートされない**。
- 各ノートはその時点のオクターブ (`O`)、デフォルト長 (`L`)、ボリューム (`V`)、テンポ (`T`) の状態で記録される。

### ディレクティブ

#### `T<数値>` — テンポ（BPM）

テンポをBPM（Beats Per Minute）で設定する。

- **デフォルト値:** `120`
- 例：`T160` → 160 BPM

テンポは途中で変更可能。異なるテンポで記述されたノートは、内部でノート長が自動的に調整される（後述の「テンポとタイミング」参照）。

#### `O<数値>` — オクターブ

オクターブを設定する。

- **デフォルト値:** `4`（C4 = ミドルC）
- 例：`O5` → オクターブ5

#### `L<数値>` — デフォルトノート長

以降のノートのデフォルトの長さをtick数で設定する。

- **デフォルト値:** `4`
- 例：`L480` → 480 tick

`ticks_per_beat` が 480 の場合、`L480` = 四分音符、`L240` = 八分音符、`L960` = 二分音符に相当する。

#### `V<数値>` — ボリューム

ボリュームを設定する。

- **デフォルト値:** `100`
- 例：`V12` → ボリューム12
- 音声合成時のゲインは `volume / 100` となる（`V100` で最大振幅）。

#### `R` — 休符

現在のデフォルト長（`L` で設定された値）の分だけ、無音で時間を進める。

#### `>` — オクターブ上げ

現在のオクターブを1つ上げる。`O4` の状態で `>` を使うと `O5` になる。

#### `<` — オクターブ下げ

現在のオクターブを1つ下げる。`O5` の状態で `<` を使うと `O4` になる。

### コメント

```
REM コメント本文 ;
```

`REM` トークンからセミコロン(`;`)で終わるトークンまでが無視される。セミコロンはトークンの末尾にあればよい（`text;` でも `;` でも可）。

```
REM これはコメント ;
REM これもコメント;
```

### 和音（コード）

```
BEGIN <ノート...> END
```

`BEGIN` と `END` で囲まれたノートは同時に発音される。和音の長さは、含まれるノートの最大長で決まる。

```
REM Cメジャーコード ;
BEGIN C E G END
```

`BEGIN`〜`END` ブロック内でもディレクティブ（`O`, `L` 等）を使用できる。これにより、和音内の各ノートに異なるオクターブや長さを指定できる。

```
BEGIN
    O3 L512 A
    O4 L512 C
    O4 L512 E
    O5 L128 A
END
```

上の例では、下3音は512 tickの持続音、最高音のAは128 tickで発音され、和音全体の長さは512 tickとなる。

**注意:** `BEGIN`/`END` 内で変更したディレクティブの状態（`O`, `L`, `V`, `T`）はブロック終了後も持続する。

### テンポとタイミング

#### tick と実時間の関係

- 内部タイミングの基本単位は **tick**
- `ticks_per_beat` パラメータで1拍あたりのtick数を指定する（デフォルト: `480`）
- 実時間への変換: `ticks_per_second = ticks_per_beat * tempo / 60`

#### 複数テンポの処理

曲中にテンポ変更がある場合、パーサーは以下のアルゴリズムで処理する：

1. 全ノートの中から最大のテンポ値を **universal_tempo** として採用する
2. NoteSequence全体のテンポを universal_tempo に設定する
3. 各ノートの長さを `length * universal_tempo // tempo` で補正する

これにより、テンポが低いセクションのノートは比例的に長くなり、全体として適切なタイミングが保たれる。

### MIDIピッチ

ノートは内部的にMIDIピッチ番号に変換される。

```
pitch = 12 * (octave + 1) + note_offset
```

| 音名 | offset |
|------|--------|
| C    | 0      |
| C#   | 1      |
| D    | 2      |
| D#   | 3      |
| E    | 4      |
| F    | 5      |
| F#   | 6      |
| G    | 7      |
| G#   | 8      |
| A    | 9      |
| A#   | 10     |
| B    | 11     |

例：C4 = `12 * (4+1) + 0` = 60（ミドルC）、A4 = `12 * (4+1) + 9` = 69

#### 周波数変換

A4 = 440Hz の標準ピッチに基づく：

```
frequency = 440.0 * 2^((pitch - 69) / 12)
```

### 音声合成

- デフォルトは矩形波による合成（`to_waveform(waveform_func=...)` で正弦波・ノコギリ波に変更可能）
- 和音は各ノートの波形を加算合成
- 波形は `[-1, 1]` にクリッピング
- ビット深度: 8-bit (int8)、16-bit (int16)、32-bit (float32)
- デフォルトサンプリングレート: 44100 Hz

## セットアップ

```bash
uv sync
```

Python 3.11 以上が必要。

## CLI

```
uv run playmml <file.mml> [options]
# または
uv run python -m playmml <file.mml> [options]
```

| オプション | デフォルト | 説明 |
|-----------|-----------|------|
| `file`    | (必須)    | MMLファイルパス |
| `-o`, `--output` | なし | 出力WAVファイルパス（省略時は直接再生） |
| `--sample-rate`  | `44100` | サンプリングレート (Hz) |
| `--ticks-per-beat` | `480` | 1拍あたりのtick数 |
| `--bit-depth`    | `16` | ビット深度 (`8`, `16`, `32`) |

## サンプル

`samples/` ディレクトリにサンプルMMLファイルがある。

```bash
# Cメジャースケール
python -m playmml samples/scale.mml

# きらきら星
python -m playmml samples/twinkle.mml

# WAVファイルとして保存
python -m playmml samples/chords.mml -o output.wav
```
